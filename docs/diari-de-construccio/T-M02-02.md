## Supòsits d'implementació, per revisar
- Els camps de preu de la fitxa guarden el preu inicial; el vigent surt sempre de les versions.
- Canviar un preu demana motiu i una data d'entrada en vigor que no sigui passada.
- Les versions de preu són de només afegir a l'aplicació, sense disparador a la base de dades.
- Un tipus o un subtipus desactivat no es pot triar per a una sortida nova. Si un projecte acabat es pot fer servir no ho diu cap regla, i no es comprova.
